# 球蛇战场 · Blob & Snake Arena

球球大作战 × 贪吃蛇 融合竞技游戏。**单文件离线 HTML5**，专为 iPhone 触屏设计，同一战场里球与蛇同场厮杀。

## 一、在 iPhone 上打开

1. 把 `index.html` 通过 AirDrop / 微信文件传输助手 / iCloud 云盘 / 邮件附件 发送到 iPhone；
2. 用 **Safari** 打开（其它 App 内置浏览器可能禁用全屏）；
3. 点击浏览器底部分享按钮 → **添加到主屏幕**，之后从桌面图标进入即为全屏体验；
4. 无需联网、无需安装任何东西，进度（最高分、皮肤解锁）自动保存在本机。

> 游戏同样兼容 Android / iPad / 桌面浏览器（鼠标移动转向，空格冲刺）。

## 二、玩法速览

| 项目 | 球体阵营 | 蛇阵营 |
|---|---|---|
| 成长方式 | 吃豆 +1 质量，吞噬对手变大 | 能量攒满增长一节，越吃越长 |
| 半径 | `6 × √质量`（初始 44） | 头 `5 × √头质量`，身体 = 头 × 0.72 |
| 速度 | `250 × (44/质量)^0.16` 越大越慢 | `200 + 1.6 × 节数` 越长越快（上限 330） |
| 转向 | 6 rad/s 极灵活 | 3.2 rad/s 需要预判 |
| 撞墙 | 推回 + 流失质量，**不会死** | **当场死亡** |
| 死法 | 被更大的球 / 蛇头吞噬 | 撞墙、撞自己身体（第 4 节起）、被吞 |
| 冲刺 | 耗 6% 质量 → 1.9 倍速 1.1s | 耗 8 能量 → 1.6 倍速 1.2s |

**操控**：手指按住屏幕朝目标方向拖动即可转向（虚拟摇杆随手指滑动），松手保持前进；右下角大按钮为冲刺。

## 三、AI 生成的完整规则

### 1. 战场与回合
- 圆形竞技场，半径 2600；全场恒定 420 颗能量豆（每颗 +1 能量，吃光即时补充）。
- 单局 180 秒；玩家 + 5 球 AI + 5 蛇 AI（普通难度）。
- 时间到按实时积分排名；**玩家阵亡立即结算**，名次按阵亡瞬间冻结；AI 阵亡 3.2 秒后重生。

### 2. 成长公式
- 球：初始质量 44。吃豆 +1；吞噬按下列比例增加质量。
- 蛇：初始 16 节 + 64 点成长槽；能量累计到 `4 + 0.5 × 当前节数` 新增一节；蛇头质量 = `60 + 1.1 × (节数 − 8)`。
- 抑制膨胀：质量 > 220 后每秒衰减 0.35；蛇 > 45 节后缓慢退化。

### 3. 死亡判定（怎么算输）
1. **蛇撞出竞技场边界** → 死。
2. **蛇头撞到自己第 4 节以后的身体** → 死。
3. **头被更大的对手吞噬**（见下）→ 死。
4. **断尾**：蛇身被**体型大于它 1.12 倍**的对手撞到 → 从被撞节起后半段整条断裂、炸成能量豆（同级对手只能弹开）；断尾后 1.6 秒受保护不被连撕；剩余体节 < 8 时被撞击者整个吞下。
5. 球撞墙不会死，但被推回并每秒流失 4% 质量。

### 4. 吞噬判定（怎么算赢）
| 对局 | 判定 | 收益 |
|---|---|---|
| 球 vs 球 | 半径差 1.12 倍且贴近 | 大球获小球质量 85% |
| 蛇头 vs 球 | 蛇头大（阈值 1.10，略宽，体现机动优势） | 蛇获球质量 70% 转长度 |
| 球 vs 蛇头 | 球大 1.12 倍 | 球获蛇总质量 60%，蛇身炸成豆 |
| 蛇头 vs 蛇头 | 大吃小 | 获对方总质量 60% |
| 球撞断蛇身 | 球大 1.12 倍 | 获断裂部分 45% |
| 蛇头撞断他蛇身 | 蛇头大 1.12 倍 | 获断裂部分 40% |

> 防滚雪球：每节身体最多折算 3 点吞噬收益。
> 克制环：大球稳吃蛇头 → 蛇靠速度与转向绕后搏杀 → 小球被两者通吃。**体型差距决定一切，没有绝对强势阵营。**

### 5. 积分与排行榜
```
得分 = 成长量 × 3 + 吞噬对手 × 200 + 吃到食物 × 2 + 存活秒数 × 1.5
成长量 = 峰值体型 − 开局体型
```
- 局内右上角实时排行榜（全部球 + 蛇），随时看自己名次。
- 局终显示：本局得分、名次、称号（冠军/亚军/季军/强者/中游/生存者）、得分构成明细、最终十强榜。
- 最高分按阵营分别保存在本地；皮肤按综合最高分解锁。

### 6. 皮肤系统
每阵营 6 款皮肤，初始解锁 3 款，其余按**综合最高分**解锁：

| 解锁条件 | 球体 | 蛇 |
|---|---|---|
| 初始 | 星海蓝 / 熔岩红 / 翡翠 | 青竹 / 赤焰 / 幽灵白 |
| 综合最高分 ≥ 800 | 暗夜紫 | 霓虹粉 |
| 综合最高分 ≥ 2000 | 黄金球 | 黑金 |
| 综合最高分 ≥ 5000 | 彩虹球 | 极光 |

### 7. AI 对手
- 三档强度：休闲（3 球 + 3 蛇）/ 普通（5 + 5）/ 激烈（7 + 7），侵略性与走位精度同步提高。
- AI 采用 12 方向采样评分决策：追食物、猎弱者、躲天敌、避墙壁与蛇身、危险时冲刺。
- **防围猎**：同时追击玩家的 AI 超过 3 个时，追得最久的会被强制「解除追击」30–60 秒随机时间，各自寻找其他敌人，避免被群殴。

### 8. 金币 · 商店 · 道具 · 仓库
- **金币**：每局按 `存活时间 + 吃掉数量` 综合结算（约 1 秒 = 4 金币，每吃一颗豆 = 1 金币），用于购买皮肤、道具、地图。
- **商店**：主菜单「商店」，用金币购买道具；**仓库**：查看已购道具并装备，装备的道具在下一局开局消耗并生效；复活护符为被动道具，无需装备、开局自动携带。
- **道具一览**：

| 道具 | 价格 | 效果 |
|---|---|---|
| 疾风药剂 | 120 | 开局 10 秒 1.5 倍加速 |
| 生长激素 | 100 | 下一局蛇初始体长 +6 节 |
| 膨胀胶囊 | 100 | 下一局球初始质量 +40 |
| 护盾发生器 | 220 | 开局无敌 8 秒 |
| **复活护符** | 300 | **被动道具，无需装备**：开局自动携带全部库存作为本局复活次数；阵亡时自动原地满状态复活并获 3 秒无敌，HUD 显示剩余次数 |

### 9. 地图 / 刺球 / 栅栏 / 隐藏房间
- 4 张地图（积分解锁，原始旷野免费）：荆棘之地（刺球）、铁壁迷宫（栅栏）、荒芜废都（刺球+栅栏最重）。
- **刺球**：蛇碰到直接从被撞节截断、断掉部分化作金色能量豆；球碰到适当变小并在四周散出金色食物。
- **栅栏**：阻挡穿行，不会致死。
- **隐藏房间**：地图边界随机位置，30–90 秒随机时刻开放，进入得大量金色食物；不明显需自行寻找，每局不超过 3 个，AI 不能连续多次进入。
- 由蛇 / 球变化（断尾、刺球）产生的食物为**金色特殊豆**，与自动生成的白色能量豆区分。

## 四、技术说明

- 纯原生 HTML5 Canvas + JS，零依赖，单文件约 330KB；
- 空间网格（Grid）碰撞加速，11 名玩家 + 420 食物稳定 60 FPS（iPhone SE 实测）；
- WebAudio 合成音效（可静音）；localStorage 存档；
- 适配 iPhone 安全区（刘海 / Home 横条）、竖屏横屏均可。
